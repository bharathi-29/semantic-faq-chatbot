# 🤖 Semantic FAQ Chatbot

A semantic AI chatbot built using Python, Sentence Transformers, and cosine similarity for intelligent FAQ retrieval.

## 🚀 Features

* Semantic question understanding
* FAQ retrieval using embeddings
* Sentence Transformer integration
* Cosine similarity matching
* Streamlit-based web UI
* University/student assistant chatbot
* Fast and lightweight architecture

---

## 🛠️ Technologies Used

* Python
* Streamlit
* Sentence Transformers
* Scikit-learn
* NumPy
* PyTorch

## 🧠 How It Works

1. User enters a question.
2. The chatbot converts the question into embeddings using Sentence Transformers.
3. Cosine similarity is calculated between user input and stored FAQ questions.
4. The most semantically similar answer is returned.
